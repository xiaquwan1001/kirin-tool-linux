Fork build of Kirin Tool for Linux 2.4.13 (downstream of Redminote11tech/kirin-tool-linux).

This release is the 2026-11-12 audit + fix batch: the MCP contract now matches reality, every
write path is honest about success, and four new hardware-free test harnesses guard it.

Safety / behaviour
- MCP no longer claims "gate-only": flash_ota / flash_xml are marked as real writes and say so in
  initialize.instructions and in the confirm description (generated from CliWriteKind, so it cannot
  drift again). vcom_unlock / oeminfo / downgrade_enable stay plan-only (exit 4, nothing written).
- MCP rejects allow-redline (-32602, "redline override is CLI-only"): an AI client can no longer
  override a device-keyed partition by itself.
- Machine-readable gate signal on every write command and MCP call: plan-only / refused (with reason)
  / confirmed / applied. Refusals are isError=true over MCP. A refusal used to emit two JSON documents,
  which broke clients.
- GUI fastboot writes now require exit 0 AND OKAY (XML partitions, Full OTA, rescue) - no more
  "flash completed" for a rejected write.
- Serial-number (NVE) rewrite and FRP erase require an explicit confirmation dialog.
- USB Update re-confirms redline partitions that only become visible after unpacking.
- Global unhandled-exception handlers log and surface UI crashes instead of dying silently.
- Automatic pre-op backup before every real write: redline partitions of the plan + ptable are dumped
  into a timestamped directory with manifest.json (file, size, SHA256, status). Best effort: a loader
  without dump support degrades to "unsupported" plus a warning and the write continues; --require-backup
  refuses instead, --no-backup skips.
- Low-battery banner (best effort getvar) is a warning only, never a gate.
- flash-xml now skips identifiers the loader does not expose (like flash-ota); --strict-names refuses.
- New read-only `backup` CLI/MCP command: dumps the identity partitions (or a chosen set) plus
  `ptable` into a timestamped directory with a manifest.json; unsupported loaders are recorded, never fatal.

Robustness
- SuperMerger rejects truncated sparse headers instead of dereferencing a short buffer.
- ProcessRunner kills the whole process tree on timeout and waits for exit.
- OemInfoService uses per-instance temp files; VcomFlasher no longer leaks a SerialPort on retry.
- FastbootClient collects unlock output after process exit instead of guessing with delays.
- CLI staging directory (.kirintool-cli-tmp) is cleaned up; nullable/platform warnings reduced.

Tests and CI
- tests/{WriteGates,McpProtocol,OtaPlan,BackupPlan} added; tests/suites.txt is the single source of
  truth for both pipelines (17 hardware-free harnesses, all green).
- FlashPolicy fails hard when the CLI binary is missing (it used to skip silently).
- GitLab CI added (.gitlab-ci.yml) next to GitHub Actions: same gates, campus runner (~40 s).

Packages
- kirin-tool-linux_2.4.13_amd64.deb (GUI + CLI, self-contained; udev rule now GROUP="plugdev" on
  Debian/Ubuntu, adbusers stays on Arch)
- kirin-tool-linux-2.4.13-x86_64.AppImage (glibc 2.31 baseline)
- kirin-tool-linux-2.4.13-x86_64.tar.gz
- kirin-tool-cli-2.4.13-linux-x86_64 (also an MCP stdio server)
