## 正文

**在 Linux 上刷华为 / 麒麟手机，现在不用再装一堆半成品工具了。**

Kirin Tool 的 Linux 版我们接手后做了一条自己的维护线，叫 **refresh**（仓库名带 `-refresh` 后缀，别和原版搞混）。它不是新项目，是把原版那套「解包、刷机、救援」搬到了 Linux，并且把容易出事的地方都加上了护栏。

### 装起来有多省事

- **deb 一行**：`sudo apt install ./kirin-tool-linux_2.4.13_amd64.deb` —— 图形界面、命令行、udev 规则一次装齐，不用另外装 .NET
- **不想装**：AppImage 双击跑，或者解压 tar.gz 丢到 `~/opt`
- **只想用命令行**：一个单文件二进制，chmod 就能用

### 日常最常用的三个场景

**1）想看看包里到底有什么分区**
打开提取器，选中 UPDATE.APP，分区一个个列出来，勾上就能导到文件夹里。不需要连手机，也不需要装别的一堆解包脚本。

**2）刷机前先看一眼计划，再决定要不要真刷**
```
kirin-tool-cli flash-ota base.app --json   # 只打印计划，一个字节都不写
kirin-tool-cli flash-ota base.app --yes    # 确认没问题，再真刷
```
图形界面里也一样：点「刷写」先出一份清单，看清楚再按。

**3）怕手滑刷坏身份分区**
红线分区（oeminfo、persist、nvme 这些）默认是拒绝的，必须你亲自点头才会动；图形界面会把具体哪几个分区列出来给你看。而且每次真写之前，工具会自动把这些分区先备份成一个带时间戳的文件夹，里面有一份 manifest 记录每个文件的大小和校验值。

### 几个顺手的小细节

- 记住上次选的芯片型号、固件文件和目录，不用每回重新翻
- 浅色 / 深色主题，晚上刷机不刺眼
- 刷写进度里能看到「写入前备份」那一行，知道它到底备了什么
- 低电量会提示一句（只是提示，不拦你；但真的建议 50% 以上再动手）

### 还能让 AI 帮你打下手

工具自带 MCP 接口，可以直接接进支持 MCP 的 AI 客户端。让它帮你`doctor` 一下、看看设备连没连、读设备信息、分析一份计划，这些都很方便。

但**所有真正会写设备的操作，都必须你本人确认**；红线分区更是只能在命令行由人手动加参数——AI 客户端在协议层就被拒绝，没法自己给自己开权限。这一点是刻意这么设计的。

### 最后提醒一句

刷机有风险：数据会没，型号和固件不对可能直接变黑砖。目前完整刷机流程只在一台华为 P40 Pro（ELS-AN00）上跑通，其他机型、其他麒麟芯片请不要想当然；命令输出的计划和你自己设备的实际情况，永远优先。
