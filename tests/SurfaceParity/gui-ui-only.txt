# GUI handlers that are pure UI plumbing: they open a file dialog, toggle a selection,
# switch a page or copy text. They never touch the device and therefore cannot be a
# capability of the CLI/MCP surface.
#
# Format:  <method name in MainWindow*.cs>   # <reason>
# Rules (enforced by tests/SurfaceParity, gates E/E3):
#   * the method must still exist in MainWindow*.cs (stale lines fail);
#   * the line must carry a reason;
#   * a handler that IS registered in CapabilityRegistry must not appear here.
#
# Anything that reaches fastboot/adb/USB does NOT belong in this file: register it in
# Services/Capabilities/CapabilityRegistry.cs instead (with a GuiOnlyReason if it has no
# CLI/MCP face yet).

HandleNavigation                                  # 左侧导航切页，只改可见性
